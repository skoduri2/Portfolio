Resistive-Key Vehicle Safety System

The Resistive-Key Vehicle Safety System is a hardware authentication prototype built around a simple idea: the physical key contains a resistance value that acts as an electrical credential. When the key is inserted, the circuit converts that resistance into a voltage and compares it against an expected range before allowing the system to proceed.

I implemented the validation path with comparator circuits and AND-gate logic rather than relying on software for the authentication decision. I also added a three-second delay after an unsuccessful attempt, which makes rapid resistance guessing more difficult. The project was a useful exercise in translating a security concept into analog thresholds, timing behavior, and discrete logic that can be observed and debugged directly on the bench.
