Five-Finger Robotic Hand Controller

GitHub repository ↗

This project is the electrical backbone for a tendon-driven five-finger robotic hand. I’m designing a custom four-layer board in KiCad that combines the main controller, actuator communications, programming and debug access, and power distribution into one compact platform. The board centers on an ESP32-S3 and is being designed to control ten DYNAMIXEL XL330-M288-T actuators without requiring a separate controller for each motor.

A major design challenge is making the low-voltage logic and high-current motor system coexist reliably. The communication side uses a shared 3.3 V TTL half-duplex bus, while the power architecture separates the logic and motor rails from a 3S battery source. I’m also integrating USB-C programming, boot/reset circuitry, ESD protection, test points, and expansion interfaces, while budgeting current and planning copper and thermal performance for a 5 V rail that may need to sustain roughly 15–16 A.
