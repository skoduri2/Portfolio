Static HTML/CSS portfolio; no build tools required.

- Redesigned the hero so the video fades into the portfolio title and introduction.

## Preview locally
Open `index.html`, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy
Upload this folder directly to GitHub Pages, Netlify, or Vercel.
